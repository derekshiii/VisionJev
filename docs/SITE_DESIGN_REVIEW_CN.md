## 1. 项目背景

本仓库包含两条研究线：

- **VisionJev**（主线）：面向快速结构化视觉决策的小型多模态模型。基于 [Bespoke Nimble](https://github.com/bespokelabsai/nimble) 与 Qwen3.5 原生视觉语言骨干，将文本单模态决策流程扩展到图像与文本判断标准。研究路线为 **视觉证据 → 结构化判断 → 下游动作**。
- **DriveJev**（下游应用）：自动驾驶规划判断，已在 NAVSIM 上完成评测。

本次要建设的是 **VisionJev 的项目主页**（GitHub Pages 静态站点），目标是让研究同行能够判断方法是否可信、能否复现。

**站点地址**：`https://derekshiii.github.io/VisionJev/`

## 4. 设计决策记录

| # | 决策 | 理由 | 被否方案 |
| --- | --- | --- | --- |
| D1 | GitHub Pages 项目主页（非个人 Profile README） | 受众是判断方法可信度的研究者，需要承载图表与实验细节 | Profile README 无法承载；仅改造 README 表达力受限于 Markdown 渲染 |
| D2 | VisionJev 为主角，DriveJev 作下游板块 | 与当前主线分支一致 | 双项目平级（稀释焦点）；只讲 VisionJev（丢失迁移叙事） |
| D3 | 站点与代码同仓库，不另建站点仓库 | 图表与数据同源，避免跨库同步 | 独立站点仓库（内容分家，维护成本最高） |
| D4 | 零构建单页静态站点 | 单页、更新频率低、读者只关心可信度；三年后回来改一行字不需装环境 | Actions 构建（机制过重）；学术模板改造（需读懂他人 Jekyll 结构） |
| D5 | 站点文件放仓库根目录 | 可直接引用 `assets/figures/*.svg`，无需复制图片 | 放 `docs/`（图片路径断裂，需复制导致不同步） |
| D6 | 主标题走**路线陈述型**口径 | 与 README 克制口径一致，无需限定语；气势由排版承担 | 研究问句型（修辞味偏重）；产品宣示型（与 README 口径冲突） |
| D7 | 先做中文单页 | 结构未定稿前不做双语，避免双份内容同步维护 | 英文优先；中英双语同步上线 |
| D8 | 暂不做暗色模式 | 两套配色维护成本高；CSS 变量结构预留 | 首版即支持 |
| D9 | 视觉风格参照 omnijev.net | 所有者指定 | 通用学术项目页范式 |

### 5.3 已知视觉冲突（**需专家意见**）

已有图表由 `scripts/plot_results.py` 生成，采用**论文风格**：

- 衬线体 `STIXGeneral`
- 低饱和配色：灰 `#92999f`、青 `#177b79`、蓝 `#3c6089`
- 面向印刷（同时输出 PDF），300 dpi

目标页面风格则是**无衬线 + 高饱和蓝紫渐变**。两者并置会明显不协调。三种处理方式各有代价：

1. **改图表**：修改 `plot_results.py` 配色与字体 → 但会同时改变 README 中的图表，影响既有引用与已发布版本的一致性
2. **改页面**：页面配色向图表靠拢 → 放弃指定的参考风格
3. **双版本**：为站点单独生成一套网页风格图表 → 引入"同一数据两套外观"，需明确标注

## 6. 技术实现与部署

### 6.1 文件结构

```
VisionJev/  (main 分支根目录)
├── index.html        ← 新增
├── site.css          ← 新增

├── assets/figures/   ← 已存在，直接引用

└── scripts/plot_results.py
```

### 6.2 部署步骤

```bash
git remote add vision git@github.com:derekshiii/VisionJev.git
git push vision visionjev:main
git push vision drivejev:drivejev
```

随后在仓库网页 Settings → Pages → Source 选择 `main` 分支 / 根目录。

### 6.3 副作用

从根目录发布后，`docs/*.md`、`results/summary.json`、`references.bib` 等文件将可通过网页直接访问。这些文件在公开仓库中本已可见，**但以网页形式暴露会改变其被索引与抓取的方式**。

## 9. 附录

### 9.1 参考站风格要点

参照 omnijev.net 的视觉语言：浅色底 + 极淡紫蓝光晕；超大号粗体标题，后半句用蓝紫渐变；胶囊按钮（主按钮渐变填充，次按钮白底描边）；卡片白底圆角 + 顶部彩色渐变细线 + 圆角方形图标底；每节"居中大标题 + 灰色副标题 + 内容区"，节间距极大；数据点为大号彩色数字 + 小号灰色标签，中间竖线分隔。

### 9.2 相关文件

- `README.md` / `README_CN.md` — 页面文案来源
- `docs/VERIFICATION.md` — 数值口径与保留意见
- `docs/MULTIMODAL_PLAN_CN.md` — 实验协议
- `results/summary.json` — 数值唯一来源
- `scripts/plot_results.py` — 图表生成
